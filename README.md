 
## 1. Core Java (Foundational)
This covers the basic building blocks required for any Java-based development. 

* Introduction: 
 
 History, features, and the Java environment including JVM (Java Virtual Machine), JRE (Runtime Environment), and JDK (Development Kit).

* Language Fundamentals: 

 Data types, variables, operators, and control flow (if-else, switch, loops).

* User I/O : Scanner class.
* 
* Number, Math,Arrays & Strings: 

  Single and multi-dimensional arrays; String immutability and classes like StringBuilder and StringBuffer.

* Object-Oriented Programming (OOP):
   Classes and Objects: Definitions, constructors, and the this keyword.
   Four Pillars: Inheritance, Polymorphism (Overloading/Overriding), Abstraction (Abstract classes & Interfaces), and Encapsulation.
Also - Concepts of association aggregation and composition


* Exception Handling: 
    The try-catch-finally hierarchy, custom exceptions, and the difference between checked and unchecked exceptions.

* Collections Framework: 
  
 Working with data structures like List (ArrayList, LinkedList), Set (HashSet, TreeSet), and Map (HashMap, TreeMap).

## 2. Advanced Java (Enterprise & Web)

* Input/Output (I/O): Working with file streams, serialization, and NIO (New I/O). 
* Multithreading & Concurrency: Thread lifecycle, synchronization, and advanced utilities like ExecutorService and Virtual Threads (introduced in Java 21).
* Database Connectivity (JDBC): Connecting to RDBMS, executing SQL queries, and managing transactions.
* Web Development Basics:
* Servlets: Lifecycle, request/response handling, and session management.
* JSP (JavaServer Pages): Dynamic content creation using directives, actions, and implicit objects.


## 3. Modern Java & Ecosystem (Java 8 to 21)
Current industry standards require knowledge of "Modern Java" features and popular frameworks.

* Java 8+ Features: Lambda expressions, Functional Interfaces, and the Stream API.
* Java 21 Updates: Pattern matching for switch, record patterns, and sequenced collections.

* Frameworks (Standard Industry Path):
* Spring & Spring Boot: Dependency Injection (DI), Inversion of Control (IoC), and building REST APIs.
* Hibernate: Object-Relational Mapping (ORM) for simplified database interactions.
* Unit Testing: Writing test cases using JUnit and Mockito.
